Asgard Shop Autobuy

Tutorial — Hero Wars Helper userscript

⬇ Download AsgardShopAutoBuy.user.js

1

Install the script

First of all, install this script in Tampermonkey together with the latest version of Hero Wars Helper.

2

Open the menu

You will find the menu in the "others" menu of Hero Wars Helper.

The "Asgard Shop AutoBuy (settings)" entry in the action menu.

3

Import the settings from the web

You have to import the settings from the web: open the Import/Export tab, load the URL and run the Import (preview).

Actually, only the OSH settings are available, not Maestro.

1) Import/Export tab  ·  2) Load from web  ·  3) Import (preview).

4

Purchase the buffs

Open the Buy tab (arrow 4) to see the buy plan, then click Buy buffs (arrow 5): it is just one click plus a confirmation.

4) Buy tab  ·  5) Buy buffs + confirm.
